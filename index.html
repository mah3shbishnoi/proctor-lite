    LRU Cache with Time-Bounded Expiration

    Protected Content

    Design and implement a data structure for a Time-Aware Least Recently Used (LRU) Cache that supports the following operations in O(1) average time complexity:

    • get(key, nowMs) — Return the value associated with key if it exists and has not expired at timestamp nowMs; otherwise return -1.
    • put(key, value, ttlMs, nowMs) — Insert or update the value of key with an expiration time of nowMs + ttlMs. If the cache reaches its capacity, evict the least recently used key first.
    Example:
const cache = new TimedLRUCache(2);
cache.put("session_a", 42, 1000, 100); // expires at 1100ms
cache.get("session_a", 500);           // returns 42
cache.get("session_a", 1200);          // returns -1 (expired)
